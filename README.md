# NVcam iOS
Virtual camera system for jailbroken iOS devices with mediaserverd hooking via Theos/Logos for MDM deployment.

## Features
- Virtual Camera App monitoring injected frames
- Theos/Logos Hook Module for AVFoundation/mediaserverd APIs
- Jailbreak Compatible with MobileSubstrate
- MDM Integration ready
- Frame Injection capability

## Build
Push to main branch. GitHub Actions will build unsigned IPA. Download artifact `NVcam-unsigned-ipa`.

## Legal
For authorized testing and MDM scenarios only. Use on devices you own or have authorization. Requires jailbroken device.
