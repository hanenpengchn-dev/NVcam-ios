# VCam Test Tweak — App 白名单
# ---------------------------------------------
# 用法：一行写一个 App 的 bundle id（区分：只对这里列出的 App 生效）
#   · 本文件里全部是注释（或文件不存在）时 = 对所有 App 生效
#   · 只要写了至少一个 App，就进入"白名单模式"：只有列出的 App 显示悬浮钮
#   · 以 # 开头的行是注释，会被忽略
#
# 示例（把 # 去掉即生效）：
# com.ss.iphone.ugc.Aweme     # 抖音
# com.tencent.xin             # 微信
#
# 保存后：把目标 App 从后台划掉、重新打开即可（首次由 App 启动时读取）
